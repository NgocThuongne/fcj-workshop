###  [Blog 1 - Automate medical record digitization with Amazon Bedrock Data Automation and AWS HealthLake](3.1-Blog1/)
This blog introduces a solution that leverages Generative AI to automate the digitization of unstructured medical documents (scans, PDF files) at an enterprise scale. You will learn how to build a serverless pipeline combining the intelligent information extraction capabilities of Amazon Bedrock Data Automation (BDA) with the standardized storage of AWS HealthLake. The solution eliminates tedious manual data entry, minimizes clinical errors, and breaks down medical data silos in compliance with the international FHIR R4 health data standard.

###  [Blog 2 - New advanced log analytics capabilities for Amazon CloudWatch](3.2-Blog2/)
This blog summarizes 5 powerful new features of Amazon CloudWatch Log Analytics (Facets, Lookup Tables, Parameterized Queries, JOIN & Sub-queries, Scheduled Queries). The article focuses on solving real-world operational challenges such as eliminating manual query writing, enriching data context, and optimizing multi-source log correlation. Consequently, it helps engineering teams accelerate security incident investigations and Root Cause Analysis (RCA) across large-scale systems.

###  [Blog 3 - Secure multi-tenant RAG with Amazon Bedrock and Verified Permissions](3.3-Blog3/)
This blog introduces a solution for building secure multi-tenant Retrieval-Augmented Generation (RAG) applications on AWS without duplicating infrastructure for each department. The article guides you through setting up a two-layer defense-in-depth security model combining Amazon Bedrock and Amazon Verified Permissions. By utilizing the Cedar policy language and metadata filtering, the system ensures absolute data isolation at retrieval time, completely mitigating the risk of sensitive information leakage.
