# Summary Report: “AWS Vietnam Community Day 2026”

### Event Objectives

- Access advanced security solutions combining application firewalls and artificial intelligence.
- Explore specialized data storage technologies (Graph Database) and application packaging (Containerization).
- Gain deep insights into network infrastructure serving real-time online gaming systems.
- Outline career development roadmaps in systems engineering and performance optimization methods for teamwork.

### Speakers

- **Bao Huynh** – Speaker on Docker & Containerization technology.
- **Le Hoang Gia Dai** – Speaker on Advanced Systems Security.
- **Nguyen Quoc Bao** – Speaker on Cloud Game Infrastructure Architecture.
- **Truong Phuoc** – Speaker on Soft Skills and Team Management.
- **Viet Phat** – Speaker on Graph Databases and Digital Knowledge.
- **Vinh Tran** – Speaker on Career Roadmap Guidance in Systems Engineering.

### Key Highlights

#### 1. Docker - A containerization technology

**Speaker:** Bao Huynh – Speaker on Docker & Containerization technology.

- Introduced the core nature of containerization technology and how it completely resolves the "runs on my machine but fails on the server" problem.
- How to optimize source code packaging and manage isolated dependencies to ensure application consistency from development to deployment.

#### 2. Combining AWS WAF with Machine Learning

**Speaker:** Le Hoang Gia Dai - Speaker on Advanced Systems Security.

- Dived deep into security solutions by integrating Web Application Firewall (AWS WAF) with Machine Learning models.
- Explored mechanisms to automatically analyze unauthorized access behaviors, detect sophisticated evolving threats, and proactively block cyberattacks in real-time instead of relying solely on traditional static rules.

#### 3. Multiplayer in the Cloud: Complexities

**Speaker:** Nguyen Quoc Bao

- Analyzed the major technical challenges when operating multiplayer games on cloud platforms.
- Addressed data synchronization across players, cloud bandwidth optimization, latency control, and designing systems that auto-scale under sudden spikes in user traffic.

#### 4. Effective Teamwork

**Speaker:** Truong Phuoc

- Synthesized core models and methodologies to build a cohesive and high-performing team.
- Addressed fair workload distribution, optimized internal communication flows, and resolving conflicting opinions arising during project development.

#### 5. AWS Neptune for Building a Graph Knowledge Base

**Speaker:** Viet Phat

- Introduced the capabilities of graph databases through the AWS Neptune service.
- Demonstrated how to apply nodes and edges to build complex Knowledge Bases, handling multi-layered data relationships that traditional Relational Database Management Systems (RDBMS) struggle to process efficiently.

#### 6. From IT Helpdesk to Senior Sysadmin: Journey and Challenges

**Speaker:** Vinh Tran

- An inspiring story tracing a real-world career path starting from a basic technical support role (IT Helpdesk) to a senior systems specialist (Senior Sysadmin).
- Outlined key mindset shifts, essential technical skills to accumulate, and how to navigate the operational pressures of large-scale systems to advance one's career.

### Key Takeaways

#### Technical Mindset

- Modern systems security is no longer about static blocking configurations; it requires AI/ML integration to actively adapt to new forms of attack.
- Docker and containerization are mandatory standards for building modern software infrastructure, enabling applications to run independently and stably.
- Choosing the right database architecture (such as using AWS Neptune for graph databases) directly determines the performance of systems with complex interconnected data relationships.
- Online gaming network infrastructure demands extremely strict system design considerations regarding bandwidth and latency.

#### Self-Development Mindset

- Career paths (such as progressing from Helpdesk to Sysadmin) are a series of challenges requiring persistence and continuous self-improvement across both breadth and depth.
- Individual performance is only one part of the equation; collaborative thinking and aligning around shared team goals are the ultimate determinants of product success.

#### Practical Skills

- Methods for integrating AWS WAF with Machine Learning to protect endpoints for web applications.
- Skills in packaging, optimizing size, and managing container lifecycles using Docker.
- Methods for building relationship diagrams and modeling graph-based data in the cloud.
- Practical communication and task-management rule sets to improve teamwork quality.

### Applying to Work and Studies

- Implement Docker containerization for all group assignments and personal projects to gain familiarity with real-world container environments.
- Research and experiment with AWS WAF or basic security mechanisms for backend applications to enhance product security.
- Apply Truong Phuoc's teamwork rules to school project meetings, focusing on clear task decomposition and transparent progress tracking.
- Create a long-term personal skills roadmap based on Vinh Tran's insights to evaluate current progress and prepare for upcoming internships and job applications.

### Event Experience

The third session of the event series provided a highly balanced perspective, diving deep into challenging real-world enterprise problems. The beauty of this session lay in its blend of hardcore technical topics (such as AWS WAF with ML, AWS Neptune, and Multiplayer Cloud) with very relatable personal stories regarding career roadmaps and soft skills.

I was particularly inspired by Vinh Tran's talk on transitioning from Helpdesk to Senior Sysadmin. It helped a tech student like me understand that no starting point is too humble; what matters is the accumulation roadmap and the courage to face large-scale system pressures.

#### Lessons Learned

- Technology is constantly shifting toward automation and intelligence (such as Docker for environmental consistency or WAF with ML for defense).
- Every great systems specialist starts with the fundamentals; troubleshooting mindsets and working under pressure are keys to breakthrough growth.
- Effective teamwork doesn't mean a complete absence of debate, but rather establishing processes to transform those debates into product improvements.
