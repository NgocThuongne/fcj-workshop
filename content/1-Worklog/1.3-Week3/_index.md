* Practice setting up the AWS Budgets expenditure management tool to closely monitor cloud service costs.
* Master practical authorization steps within the system using AWS IAM by administering Users, Groups, and Roles, and configuring Switch Role.

### Week 3 Achievements:

* **Effective Cloud Budget Control:**
  * Successfully configured financial alerts in AWS Budgets with both forecasted and actual cost thresholds.
  * Clearly understood the automated mechanism that sends email notifications when account spending trends exceed the pre-scheduled budget limits.

* **Mastering Practical AWS IAM Configuration Skills:**
  * Learned how to create, manage, and group users (IAM Users & Groups) systematically.
  * Personally built policies (IAM Policies) and roles (IAM Roles) to delegate temporary access credentials.
  * Proficiently practiced the Switch Role feature from an Operator User account to the Admin Role, adhering to the principle of avoiding using the Root Account for daily operations.
  * Successfully implemented the Principle of Least Privilege in practice.

* **Deep Understanding of AWS Physical Infrastructure (AWS Data Center):**
  * Grasped how AWS designs its data centers to guarantee high availability (High Availability) and fault tolerance (Fault Tolerance).
  * Completed simulation labs and infrastructure diagrams to visualize AWS's physical network structure.
